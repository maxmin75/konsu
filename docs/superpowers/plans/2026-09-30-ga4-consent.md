# GA4 consent controller Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add GA4 Measurement ID `G-QVQMFTCXRF` to every Konsu page after explicit analytics consent.

**Architecture:** The root layout mounts a small client component. It stores one first-party consent preference and conditionally renders Google’s `gtag.js` only for visitors who granted Analytics.

**Tech Stack:** Next.js 16, React 19, TypeScript, Node’s built-in test runner.

---

### Task 1: Prove the intended integration contract

**Files:**
- Modify: `package.json`
- Create: `test/google-analytics-consent.test.mjs`
- Modify: `src/app/layout.tsx`
- Create: `src/app/analytics-consent.tsx`

- [ ] **Step 1: Enable the project test runner and write the failing test**

```js
test("GA4 is mounted through a consent controller", () => {
  assert.match(layout, /import \{ AnalyticsConsent \} from "\.\/analytics-consent";/);
  assert.match(layout, /<AnalyticsConsent \/>/);
  assert.match(consentComponent, /const GA_MEASUREMENT_ID = "G-QVQMFTCXRF";/);
  assert.match(consentComponent, /consent === "granted"/);
  assert.match(consentComponent, /src=\{`https:\/\/www\.googletagmanager\.com\/gtag\/js\?id=\$\{GA_MEASUREMENT_ID\}`\}/);
});
```

Add `"test": "node --test test/*.test.mjs"` to `package.json` so the existing Node test convention can run in a clean checkout.

- [ ] **Step 2: Run the test to verify it fails**

Run: `npm test -- test/google-analytics-consent.test.mjs`

Expected: FAIL because the root layout does not import or render `AnalyticsConsent`.

- [ ] **Step 3: Add the consent controller and mount it globally**

`AnalyticsConsent` reads and writes `konsu_analytics_consent`, offers Accept / Reject and a later change link, and uses `next/script` only while the preference equals `granted`. Add `<AnalyticsConsent />` immediately after `{children}` in `RootLayout`.

- [ ] **Step 4: Run the focused test**

Run: `npm test -- test/google-analytics-consent.test.mjs`

Expected: PASS.
