# Konsu

Sito Next.js indipendente per KONSU Parrucchieri Estetica Solarium.

## Sviluppo locale

```bash
npm install
npm run dev
```

Il sito locale viene servito da Next.js, di default su `http://localhost:3000`.

## Build

```bash
npm run lint
npm run build
```

## Deploy

Il progetto e' pronto per Vercel:

- Framework: Next.js
- Build command: `npm run build`
- Project root: questa cartella
- Asset locali: `public/konsu`
